# 页面精简、本地优先与阶梯时间轴

2026-10-20，用户要求：有本地数据时优先展示；去掉不必要的英文提示，保持呼吸感；优化整体交互；时间轴支持展开并呈阶梯式展示。基线 `f7830fe`。

- 本地优先：新增 `GET /api/sources` 返回本机数据是否就绪、是否有上次扫描缓存及最近活动时间。页面启动先探测：已就绪直接打开本机数据；仅有缓存（服务重启后）先做一次增量只读扫描再打开；都没有才用演示数据。日期范围选能覆盖最近活动的最窄预设（今天 / 7 天 / 30 天 / 全部）。`?source=demo|local` 可固定来源。重启后首次扫描以缓存投影为对比基线，不把已知轮次计为新增。
- 去英文与减噪：删除品牌英文副标题、工作区标签、版本英文口号、英文日期戳、各分区英文小标和 DEMO/LOCAL 标记、顶部面包屑栏；Token 分项改为中文。本机状态压成一行，扫描明细收进“扫描详情”。指标定义、口径说明与统计公式不变。
- 交互：时间轴视窗预设改为分段按钮，自定义起止收进“自定义范围”；项目筛选改为可切换标签；字号统一到 12–14px，减少边框与分隔。
- 阶梯时间轴：多轮会话左侧可展开，展开后每轮单独一行，按开始时间逐级下移并缩进；下一轮起点画竖向衔接线；会话行保留淡化的汇总。支持“展开 / 收起全部轮次”。点击任意条目仍进入会话详情。
