# 项目优先时间轴与 Cursor 时长展示

2026-10-20 用户反馈：同一实际代码项目下有多个会话，默认逐会话展示使时间轴过碎；Cursor 列表 AI 执行累计全是 N/A，已有记录时长不可见。

- 默认每个项目一行；项目可展开为会话，会话再展开轮次。总览预览和完整时间轴共用此行为，项目名/来源数/会话数可见。保留逐轮下钻、缩放、筛选和刷新。
- 聚合的是绘图行：AI 区间按项目取并集，中间空闲不连成连续执行；闭合等待按项目取并集并扣除已有执行覆盖，避免盖住执行。输入与未知标记去重，同一时间重叠会话保留详情。统计仍按原轮次计算工作量和全局并发，不把项目数当并发数。
- 项目名相同但匿名目录标识不同不自动合并，保留已有手动合并分组。
- Cursor 将可见轮次的已记录 turnDurationMs 去重后累计，在会话列表和详情直接显示，标注“Cursor 记录”和覆盖轮数。没有记录仍为 N/A；按该轮用户输入的事件时间整笔归属，不声称按日期精确裁切或等同 Codex 边界计时。
- 不从记录时长反推绝对完成时间；Cursor 执行区间、闭合等待、Token 及并发仍保持未知，KPI 不混加无法定位的时长。
- 更新合成验收，覆盖项目默认聚合、展开两层、区间并集/空闲/重叠、点击下钻、数值不变与 Cursor 列表记录值可见。
