# 03: 本机只读日志与刷新

Status: ready-for-agent
Blocked by: 02

**What to build:** 用户主动切换本机数据并刷新，看到安全归一化的真实日志分析与覆盖诊断；源日志不变，重复刷新不增加用量。

- [ ] 导入入口只访问配置日志根，服务仅绑定 loopback。
- [ ] SQLite/API 不包含真实路径、消息或工具内容。
- [ ] 重复扫描、追加、截断和归档重复通过 HTTP 入口验证。
- [ ] Fork 作用域冲突排除并说明，输入观测延迟不算精确等待。
- [ ] 对实际本机日志完成只读冒烟并记录覆盖限制。
