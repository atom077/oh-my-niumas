# 可核查的项目名称与会话标题

2026-10-20。用户要求按 Codex 会话列表显示摘要标题，页面使用项目、会话等正式概念，方便迁移核查。基线 `5fbca0c`。

- UI 导航统一“总览 / 项目 / 会话 / 时间轴”，字段、筛选、空态及操作去除工地/牛马花名册/考勤等业务别称；保留产品品牌 oh-my-牛马s。
- 会话标题从本机 `session_index.jsonl` 的 `id/thread_name/updated_at` 读取，以稳定会话标识匹配；选最新有效标题。索引缺失时显示“未命名会话”并说明，不从提示词提取标题，不生成摘要，不把 ID 当主要名称。
- 项目仍按起始 cwd 分组；展示手动别名优先，否则使用起始目录的末级名称，不输出绝对路径。保持现有匿名内部 ID，使已保存分组和备注继续有效。
- 用户授权在本机页面展示已有标题和项目目录名，替代早期默认匿名名称策略。标题只在内存装载，目录末级名允许进入本地白名单缓存；原始提示词、工具内容、完整路径仍不落库、不返回页面。标题中可识别的绝对路径以占位符替换；不把真实标题写入仓库截图或 fixture。
- 每次刷新重读有界索引；标题变更无需重读未变的日志。缓存版本升级后重新投影以补充目录名。索引缺失、无效及符号链接安全处理，既有统计口径不变。
- 沿用已确认的 HTTP 导入/分析和浏览器两个测试入口，验证标题匹配/刷新/搜索、回退、原始数据只读、别名与分组保留，以及四页正式命名。
