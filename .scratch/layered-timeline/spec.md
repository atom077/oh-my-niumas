# 三层协作时间轴

2026-10-20 用户已确认 .local/design-previews/timeline-v3/ 三张效果图，并授权实现。

- 总览和时间轴默认展示项目活动密度，每项目一行。单日按15分钟聚合输入；多日按上海日期聚合，并提供下钻。没有输入但有已知执行的格子使用单独样式和说明。
- 选择格子进入对应小时，多日先选日期。小时默认展开当前有输入或执行的项目/会话；提供前后小时、日期选择、来源标识、闭合等待开关。
- 进入会话轮次后，按该小时的会话片段贴合分钟范围。轮次可选择，支持缩放到单轮、还原，明确未知边界与记录时长。详情可回到小时/全天。
- 真实时间连续定位，区间跨窗口按交集显示；事件不与执行条叠在同一高度，短响应有时长标签。
- 共享全局来源、日期、项目、搜索；刷新保持当前层级和选择，筛选变化重置；已有列表、备注、计时口径不变。
- 沿用现有品牌和应用外壳，无新增模拟遥测。视觉稿的文字、密度与坐标误差由真实数据计算纠正。
- 覆盖合成短轮、跨日、缺失边界、Cursor未知区间、空小时、返回及刷新。真实截图不入Git。
