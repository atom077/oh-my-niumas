# 真实验收与日常使用

2026-10-20，用户授权继续推进上轮建议的 1、2、3。基线：`5088b2d`。

1. 真实会话对照：通过应用记录接口与白名单日志核对单轮、多轮、跨日及中止；保存匿名对照结果，不保存标题、消息、真实 ID 或路径。桌面窗口读取被工具禁止，缺乏界面证据的耗时/Token 项明确待人工确认，不以接口结果替代界面验收。
2. 本地标记：项目别名、合并及恢复原始目录归属；会话备注。存于本地 SQLite，重启后保持，刷新不覆盖。原始目录证据使用匿名 ID 保留，合并后重新计算指标与筛选。用户文字不自动读取标题，不接受绝对路径文字，不改变源日志。Demo 保持独立。

测试沿用已确认入口：分析结果、浏览器交互、HTTP 导入/刷新。每个行为先写失败测试，再完成实现。验收包括持久化、恢复归属、无重复累计、定时暂停/关闭/失败恢复及隐私约束。
