# Triage Labels

技能中的五个分诊角色使用以下原始标签。本地事项通过 `Status:` 行记录分诊状态。

| 标准角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

技能要求应用某个分诊角色时，使用表中对应标签。未来如需适配其他平台的已有标签，修改“本项目标签”列。
