本目录五张图用于项目介绍与推广，全部使用人工构造的合成数据；没有读取或使用本机真实会话数据。用户提供的总览图仅作视觉风格参考，未复制到本公开素材目录。

- [总览页 PNG](overview.png)：四项 KPI、项目输入密度、按小时工作量与来源环图，数据与项目页同源。
- [时间轴·小时分段 PNG](timeline-hour.png)：同一小时内多个项目与会话的并行执行、输入活动与闭合等待。
- [时间轴·会话轮次 PNG](timeline-turns.png)：四轮执行独立展开，选中一条 11 秒响应，展示精确起止与继续放大的入口。
- [项目页 PNG](projects.png)：四个虚构项目的工作量、会话数、闭合等待与已知 Token 对比。
- [会话页 PNG](sessions.png)：虚构会话“首页体验优化”的五轮执行详情，属于示例项目“前端应用”。这是会话 tab 的下钻状态。
- [完整最终提示词](prompts.md)：内置 image_gen；总览最终提示词另见 overview-prompt.md。
- [合成数据说明](synthetic-data.json)：方便后续复用或重新制作。

## 内容与隐私核验

已逐张目视检查：所有图保持同一冰蓝玻璃风格，正确选中项目 / 会话导航；日期统一为 2026-10-22 周四；均显示“演示数据”与“示例数据 · 非真实使用记录”。未见真实项目名、个人名称、路径、账号 ID、原始提示词或本机使用数值。

项目示例合计 4 个项目、10 个会话、300 min 工作量、540,000 已知 Token；Cursor 单来源项目的 Token 显示“—”。会话示例执行 45 min、跨度 60 min、闭合等待 15 min，五轮 Token 合计 108,000，与项目汇总是包含关系。已验证所有数值加总。

这些是 UI 推广效果图，非浏览器运行截图；光效、图标和细小图形由图像模型绘制。实际数据语义沿用项目定义：Token 仅 Codex，等待不代表人工工作时长，Cursor 推算保留标记。
