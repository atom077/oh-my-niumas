# 精简 UX 与四页线框

状态：2026-10-19 设计草案；本文为文字线框，尚非可运行 Demo。依据 [PROJECT.md](../oh-my-niumas-project/PROJECT.md) 前部品牌与精简策略；统计规则见 [metrics-spec.md](metrics-spec.md)。

## 已确认范围

先核验真实日志，再实现四页合成 Fixture Demo，最后接入本机只读日志。项目按会话起始 cwd 分组；后续目录变化保留证据；只统计闭合等待。展示名称统一为 **oh-my-牛马s**。

浅色主题、大屏优先，以工地黄点缀导航、蓝色表示执行。品牌图只作为视觉方向，不直接使用效果图中的旧品牌名称、头像、数值或“效率”结论。即使精简版效果图仍有多组图表，也以文字规定的“一页一个主视觉”继续做减法。

## 全局框架

- 左侧四个入口：工地总览 / 我的工地 / 牛马花名册 / 牛马考勤，同时保留总览、项目、会话、时间轴的正式释义。
- 顶部保留日期范围、项目筛选、会话搜索；明确展示时区。默认时间区间应覆盖所选 Fixture 的数据日期，不能拿系统“今天”去筛空固定种子数据。
- 清楚显示数据源：**合成演示数据**或**本机只读数据**。两者切换必须显式，不能混算。
- 跨页保留日期和项目筛选；返回列表保留上下文。空结果提供清除筛选，读取失败不静默退回合成数据冒充成功。
- 字段缺失显示 N/A 与原因；可恢复但不完整显示“已知值 + 覆盖情况”。不提供人工投入时长或订阅扣费的伪精确结果。

## 1. 工地总览

任务：快速知道所选范围里整体运行情况，以及接下来从哪里查看。

```text
oh-my-牛马s                           日期 / 项目 / 搜索 / 时区
合成演示数据 · 非真实使用记录

AI 总工作量       活跃覆盖       平均并行倍数       已知 Token
100 min           50 min          2.0×               …
                                 100 / 50           覆盖说明

跨项目协作时间轴预览                            查看完整时间轴 →
  工地 A / 会话 A   [执行────────] …
  工地 A / 会话 B       [执行────────] …
  工地 B / 会话 C            [执行──────] …

近期活动（短列表，仅事件，不复制项目排行或趋势图）
```

只保留四项 KPI、一个主时间轴、一个简短活动列表。点击预览中的会话进入详情；“查看完整时间轴”保留当前筛选。平均并行倍数说明分母是活跃覆盖时间，不是整天时长。

## 2. 我的工地 / 项目分析

任务：选择一个项目，查看其会话构成和已知工作量。

```text
我的工地                                           日期 / 项目
项目             会话    AI 工作量    闭合等待    已知 Token    最近活动
示例工地 A        2       …             …          …            …   →
示例工地 B        1       …             …          …            …   →

点击项目 → 项目详情
面包屑：我的工地 / 示例工地 A
本项目会话列表 + “在时间轴查看此项目”
```

主内容是表格，默认不复制四张全局 KPI、不加效率矩阵、饼图或洞察评分。表头说明等待不是人工投入。原始绝对路径不在演示 Fixture 或对外响应中；本机 UI 先用安全显示名称，不向浏览器泄漏源文件路径。

## 3. 牛马花名册 / 会话分析

任务：先定位会话，再看每轮执行与等待如何交错。

```text
会话列表                                  搜索 / 项目 / 状态
会话名称         项目         AI 执行累计         会话跨度      状态
示例会话 A       工地 A        …                    …            …  →

点击会话 → 会话详情
我的工地 / 工地 A / 示例会话 A
AI 执行累计                 会话跨度
…                           …（若实时则注明截至快照时间）

Turn 时间条 / 事件流切换
第 1 轮   ●输入  [执行──────] ✓完成  [闭合等待···] ●输入
第 2 轮          [执行────────────] ?缺失结束

按需展开：Token 分项 / 数据证据 / 异常说明
```

两项时间并列，避免把会话跨度称为工作时长。开放等待只标“待下次输入”。中止、失败、历史未闭合与实时运行分别显示文字和形状；工具错误不直接标整轮失败。未验证深链能力前，会话点击只进入本产品详情。

## 4. 牛马考勤 / 时间轴

任务：在同一真实时间轴上理解多个独立会话的并行关系。

```text
牛马考勤                  日期 / 项目 / 状态 / 小时或全日缩放
图例：执行实条 · 闭合等待虚线 · 用户输入菱形 · 异常图案

固定名称列         09:00       09:20       09:40       10:00
⌄ 工地 A
    会话 A          ◆[执行────────] [等待··] ◆[执行──]
    会话 B              ◆[执行─────────────]
⌄ 工地 B
    会话 C                    ◆[执行────────]

可展开：与上方同轴的并发曲线（不增加独立仪表盘）
```

- 工地可折叠，会话行可以点击；缩放后支持横向滚动，名称列固定，所有行保持同一时间尺度。
- Hover 或键盘聚焦区间时，显示准确起止、时区、执行时长、状态、数据来源类别与可信度、可归属 Token；点击打开会话详情并保留日期。
- 等待显示可开关，但开关不改变统计定义。颜色同时配合标签、边框与图案。
- 全局顶部至多保留工作量、覆盖、平均并行三项紧凑指标；不追加等待饼图、效率洞察或重复项目表。
- 历史缺失终点的区间以不确定标记表示，不任意延伸至现在。真正实时运行按快照时间展示临时值。

## 交互验收

1. 三个 Session 的执行条能在同一时间轴正确重叠，合成样例显示 100 min / 50 min / 2.0× / 峰值 3。
2. 总览 → 时间轴 → 会话详情 → 项目列表，保留筛选并能返回；项目筛选应同时影响指标与行。
3. 时间范围裁切后条形、工作量与覆盖同步改变；日期标签明确时区。
4. 无结果、无日志、读取失败、Token 未知、历史未闭合分别可辨识。
5. 可用键盘访问筛选和会话详情，Tooltip 的关键信息也能通过聚焦或详情读取。

## 本轮不扩展的内容

Agent 控制、远程任务派发、真实账单、人工投入采集、暗色主题、可发布 Logo 和效率评分不属于首轮四页核心闭环。子 Agent 计数、费用模拟与趋势分析保留为后续问题，不用未验证信息填满界面。
