## 2026-10-20 已确认的三层时间轴

默认展示全天项目活动密度，不再在全天逐轮铺满菱形/问号。单日15分钟一格，多日按上海日历日期；交互次数用颜色，只有已知执行且无输入时用描边。选择日期和小时下钻后，仅展开当前小时有输入或执行的会话；等待开关、来源、输入聚类与区间跨界标记可核查。

小时内点会话/执行条/输入，进入当前小时片段的分钟视图。保留原始轮次编号，选择轮次显示已知起止/执行或Cursor记录值，可单轮放大、缩小、还原及返回。自动刷新保留层级、小时和所选轮次；换全局筛选重置。总览与时间轴页切换保留选择；进入完整会话详情可继续使用备注和证据功能。

原有自由区间图和并发分析保留于默认关闭的“高级区间分析”，含原有范围、Ctrl滚轮、滑块、状态筛选、项目/轮次展开；以下早期线框不再代表默认首屏。

## 2026-10-20 项目优先交互

用户确认默认以项目为时间轴一行，点击项目名/箭头/聚合条展开本项目会话，点击会话仍下钻详情，会话箭头展开轮次。支持全部项目与全部轮次展开/收起；自动刷新保留层级展开状态。项目行展示当前筛选内的会话数及来源；名称相同但目录标识不同不自动合并，继续支持本地项目合并。

聚合执行段是区间并集，空档不补齐；项目闭合等待段扣除执行覆盖，输入/未知事件去重。KPI 与同轴并发继续按独立轮次计算。以下早期逐会话默认线框以本条为准。

Cursor 列表直接展示记录时长与覆盖轮数；详情说明按输入时间整笔归属、绝对起止未知。N/A 只用于确实缺少记录的值，记录累计与可定位执行累计有明确标签。

2026-10-20 修订：通过校验的 Cursor 轮次在小时、分钟和高级时间轴显示斜纹虚线“推算执行”条，悬停与图例注明“按输入时间 + Cursor 记录时长推算”，轮次状态显示“推算完成”；未通过校验的轮次仍只显示输入点，详情说明“与消息跨度不一致或缺少校验，未绘制执行区间”。

2026-10-21 修订：所有 AI 执行条（Codex、Cursor）统一为斜纹虚线，表达“运行时”；颜色区分来源：Codex 蓝、Cursor 深色，多来源项目汇总行灰蓝，中止/失败红。推算口径改由图例“Cursor 推算执行”、悬停文案与项目标注说明，不再依赖图案。闭合等待淡化为执行条中线上的浅暖灰虚线细轨，不显示时长，仍可开关；真实 Codex 输入只有记录时间，按口径不画闭合等待。以下早期线框中的“执行实条 · 闭合等待虚线”以本条为准。

## 已确认范围

先核验真实日志，再实现四页合成 Fixture Demo，最后接入本机只读日志。项目按会话起始 cwd 分组；后续目录变化保留证据；只统计闭合等待。展示名称统一为 **oh-my-牛马s**。

## 全局框架

- 左侧四个入口：总览 / 项目 / 会话 / 时间轴，同时保留总览、项目、会话、时间轴的正式释义。
- 顶部保留日期范围、项目筛选、会话搜索；明确展示时区。默认时间区间应覆盖所选 Fixture 的数据日期，不能拿系统“今天”去筛空固定种子数据。
- 清楚显示数据源：**演示数据**或**本机只读**。有本机数据时默认打开本机来源，否则为演示数据；两者不能混算，当前来源始终有标签。
- 跨页保留日期和项目筛选；返回列表保留上下文。空结果提供清除筛选，读取失败不静默退回合成数据冒充成功。
- 字段缺失显示 N/A 与原因；可恢复但不完整显示“已知值 + 覆盖情况”。不提供人工投入时长或订阅扣费的伪精确结果。

## 1. 工地总览

任务：快速知道所选范围里整体运行情况，以及接下来从哪里查看。

```text
oh-my-牛马s                           日期 / 项目 / 搜索 / 时区
合成演示数据 · 非真实使用记录

AI 总工作量       活跃覆盖       平均并行倍数       已知 Token
100 min           50 min          2.0×               …
                                 100 / 50           覆盖说明

跨项目协作时间轴预览                            查看完整时间轴 →
  工地 A / 会话 A   [执行────────] …
  工地 A / 会话 B       [执行────────] …
  工地 B / 会话 C            [执行──────] …

近期活动（短列表，仅事件，不复制项目排行或趋势图）
```

只保留四项 KPI、一个主时间轴、一个简短活动列表。点击预览中的会话进入详情；“查看完整时间轴”保留当前筛选。平均并行倍数说明分母是活跃覆盖时间，不是整天时长。

## 2. 项目 / 项目分析

任务：选择一个项目，查看其会话构成和已知工作量。

```text
项目                                           日期 / 项目
项目             会话    AI 工作量    闭合等待    已知 Token    最近活动
示例工地 A        2       …             …          …            …   →
示例工地 B        1       …             …          …            …   →

点击项目 → 项目详情
面包屑：项目 / 示例工地 A
本项目会话列表 + “在时间轴查看此项目”
```

主内容是表格，默认不复制四张全局 KPI、不加效率矩阵、饼图或洞察评分。表头说明等待不是人工投入。原始绝对路径不在演示 Fixture 或对外响应中；本机 UI 先用安全显示名称，不向浏览器泄漏源文件路径。

## 3. 牛马花名册 / 会话分析

任务：先定位会话，再看每轮执行与等待如何交错。

```text
会话列表                                  搜索 / 项目 / 状态
会话名称         项目         AI 执行累计         会话跨度      状态
示例会话 A       工地 A        …                    …            …  →

点击会话 → 会话详情
项目 / 工地 A / 示例会话 A
AI 执行累计                 会话跨度
…                           …（若实时则注明截至快照时间）

Turn 时间条 / 事件流切换
第 1 轮   ●输入  [执行──────] ✓完成  [闭合等待···] ●输入
第 2 轮          [执行────────────] ?缺失结束

按需展开：Token 分项 / 数据证据 / 异常说明
```

两项时间并列，避免把会话跨度称为工作时长。开放等待只标“待下次输入”。中止、失败、历史未闭合与实时运行分别显示文字和形状；工具错误不直接标整轮失败。未验证深链能力前，会话点击只进入本产品详情。

## 4. 牛马考勤 / 时间轴

任务：在同一真实时间轴上理解多个独立会话的并行关系。

```text
牛马考勤                  日期 / 项目 / 状态 / 小时或全日缩放
图例：执行实条 · 闭合等待虚线 · 用户输入菱形 · 异常图案

固定名称列         09:00       09:20       09:40       10:00
⌄ 工地 A
    会话 A          ◆[执行────────] [等待··] ◆[执行──]
    会话 B              ◆[执行─────────────]
⌄ 工地 B
    会话 C                    ◆[执行────────]

可展开：与上方同轴的并发曲线（不增加独立仪表盘）
```

- 工地可折叠，会话行可以点击；缩放后支持横向滚动，名称列固定，所有行保持同一时间尺度。
- Hover 或键盘聚焦区间时，显示准确起止、时区、执行时长、状态、数据来源类别与可信度、可归属 Token；点击打开会话详情并保留日期。
- 等待显示可开关，但开关不改变统计定义。颜色同时配合标签、边框与图案。
- 全局顶部至多保留工作量、覆盖、平均并行三项紧凑指标；不追加等待饼图、效率洞察或重复项目表。
- 历史缺失终点的区间以不确定标记表示，不任意延伸至现在。真正实时运行按快照时间展示临时值。

## 交互验收

1. 三个 Session 的执行条能在同一时间轴正确重叠，合成样例显示 100 min / 50 min / 2.0× / 峰值 3。
2. 总览 → 时间轴 → 会话详情 → 项目列表，保留筛选并能返回；项目筛选应同时影响指标与行。
3. 时间范围裁切后条形、工作量与覆盖同步改变；日期标签明确时区。
4. 无结果、无日志、读取失败、Token 未知、历史未闭合分别可辨识。
5. 可用键盘访问筛选和会话详情，Tooltip 的关键信息也能通过聚焦或详情读取。

## 本轮不扩展的内容

Agent 控制、远程任务派发、真实账单、人工投入采集、暗色主题、可发布 Logo 和效率评分不属于首轮四页核心闭环。子 Agent 计数、费用模拟与趋势分析保留为后续问题，不用未验证信息填满界面。

## 日常使用补充（2026-10-20）

本机来源手动扫描后，可选择关闭 / 15 / 30 / 60 秒刷新。默认关闭；页面隐藏暂停，回到页面后重新计时，切换到合成来源关闭。刷新保持日期、项目、搜索和详情，失败保留上次数据并提示。刷新完成时间、耗时及新增/更新/移除数量放在来源说明下，不增加 KPI 卡片。

项目内折叠“管理本地项目”，按匿名起始目录编辑别名、合并组或恢复原始归属。恢复组首目录会拆开整组，普通成员则单独移出。无可用日志的组首显示相应提示，既有分组继续保留。会话详情可编辑短备注，列表显示并支持搜索；所有操作只写本地标记。

## 可核查名称（2026-10-20）

导航与表格字段统一使用正式术语。会话列表、时间轴、最近完成及详情使用 Codex 索引最新标题，缺失时显示“未命名会话”及原因。项目名称按本地别名优先、起始目录末级名其次；完整目录仍不显示。标题可搜索，原有哈希关联与已保存分组不变。

## 时间轴视窗（2026-10-20）

总览和时间轴页共享图表视窗，默认按筛选后的执行区间、输入与未知边界贴合活动并留白。预设包含贴合、完整日期范围、单日上午/下午；自定义起止需在当前统计日期内，可放大/缩小、拖动滑块及 Ctrl+滚轮。跨日轴包含日期，短于一分钟显示秒级范围。

视窗只是图表缩放，不影响顶部日期筛选及 KPI；页面明确说明。自动刷新保留手动范围，切换日期/项目/搜索后恢复贴合。并发图与主图同轴，无活动的视窗显示提示。删除 HUMAN × AI / COLLABORATION 和侧栏的 本地优先 · 只读观测 两处文字。

## 精简、本地优先与阶梯时间轴（2026-10-20）

- 本地优先：启动检测本机数据，已扫描或有上次缓存时直接打开本机来源（缓存需先自动只读重建一次），日期选能覆盖最近活动的最窄预设；都没有才显示演示数据。
- 去掉非必要英文：品牌英文副标题、工作区标签、版本口号、英文日期戳、分区英文小标、DEMO/LOCAL 标记和与标题重复的面包屑栏；日期改中文短格式。本机状态压成一行，扫描明细折叠。字号统一 12–14px，减少边框。
- 视窗控件为一行分段按钮（预设 / 缩放）+ 当前范围；自定义起止收进“自定义范围”。项目折叠改为可切换标签。
- 阶梯时间轴：多轮会话可展开，每轮一行、按开始时间逐级下移并缩进，下一轮起点画竖向衔接线；会话行保留淡化汇总，可一键展开 / 收起全部。展开只改变布局，不改变统计。

```text
› 会话 A        [执行──────][等待··]  [执行────]   ← 淡化汇总
    第 1 轮     [执行──────][等待··]
      第 2 轮                    ┆ [执行────]
  会话 B              [执行──────────]
```

混合来源时，总览/时间轴首卡与项目表将 Codex 区间时长和 Cursor 记录时长累计展示；首卡说明保留两者拆分。活跃覆盖、平均并行倍数仅含可定位区间，不将 Cursor 记录累计代入并发公式。
